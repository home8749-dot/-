## 결론

○ **1순위 추천: 단디서류** — "지원사업 서류, 단디 챙기자"
- 부산 운영자 정체성(방언 '단디' = 단단히·야무지게)과 채널 약속(서류를 빈틈없이)이 한 단어에 들어감
- 합격을 약속하지 않음 → 과장 광고 리스크 낮음
○ 2순위: **공고해석소**(전문·신뢰형) / 3순위: **붙는서류**(바이럴형, 합격 암시 리스크 있음)
○ 이번 영상 7편은 1순위 기준으로 제작. 이름이 바뀌면 다시 렌더링하는 데 1분이면 됨

## 1. 단디서류 (방언 + 산업어)

- **어원·의미**: '단디'는 경상도 방언으로 '단단히, 야무지게'. "단디 해라" = 빈틈없이 챙겨라. 서류와 결합해 "빈틈없는 서류"라는 채널의 약속이 됨
- **발음·운율**: 단-디-서-류 4음절, 받침 1개(단)로 입에 붙음. "단디"의 된소리 없는 경쾌함 + "서류"의 담백함
- **이미지 키워드**: 야무짐 · 체크리스트 · 부산 · 믿음직한 선배 · 빈틈없음
- **5축**: 직관성 ★★★★☆ (서류=지원사업 연상은 한 박자 필요) / 확산성 ★★★★★ (말하기·검색 쉬움) / 파급력 ★★★★☆ (방언이 개성) / 격조 ★★★★☆ (가벼운 방언을 '서류'가 받쳐줌) / 리스크↓ ★★★★☆ (합격 약속 없음, 상표 검색 필요)
- **강점**: ① 운영자 거점(부산)이 자연스럽게 브랜드 자산이 됨 ② 약속이 '합격'이 아니라 '꼼꼼함'이라 신뢰형 ③ 도장·체크 표시 같은 시각 모티프로 번역하기 쉬움
- **약점**: ① 비경상권 시청자에겐 '단디' 뜻을 한 번 알려줘야 함 ② '서류'만 보면 행정서류 대행 채널로 오해 가능
- **리스크**: ① 동일·유사 상표 존재 가능성(키프리스 확인 필요) ② 핸들 선점 여부
- **적합 라인**: 체크리스트형 쇼츠, "제출 전 점검" 시리즈, 가이드 PDF 상품명(「단디 체크리스트」)
- **시각 방향**: 원고지 격자 + 인주 도장 + 형광펜 — "서류를 꼼꼼히 들여다보는" 장면

## 2. 붙는서류 (언어유희)

- **어원·의미**: '붙다' = 합격하다 / 서류를 붙이다. 이중 의미
- **발음·운율**: 붙-는 된소리가 강해 기억에 남음
- **이미지 키워드**: 합격 · 직설 · 바이럴 · 결과 중심
- **5축**: 직관성 ★★★★★ / 확산성 ★★★★★ / 파급력 ★★★★★ / 격조 ★★★☆☆ / 리스크↓ ★★☆☆☆ (합격 암시 → 불합격 시청자 반감·과장 인상)
- **강점**: ① 가장 직관적 ② 썸네일·캡션에서 강함 ③ 상품명 확장 쉬움(「붙는 사업계획서」)
- **약점**: ① 결과를 약속하는 인상 ② 유료 상품 판매 시 "합격 못 하면?" 질문을 부름
- **리스크**: ① 광고 표현 과장 인상 ② 유사 표현 다수 사용 중일 가능성
- **적합 라인**: 짧고 강한 팁 위주, 바이럴 실험용 서브 채널명으로 적합

## 3. 공고해석소 (산업어 + 모던 후행어)

- **어원·의미**: 공고문을 '해석'해주는 곳. 연구소·상담소 계열 후행어로 전문성
- **발음·운율**: 5음절로 다소 길지만 의미가 또렷함
- **이미지 키워드**: 전문 · 분석 · 신뢰 · 차분함 · 정리
- **5축**: 직관성 ★★★★★ / 확산성 ★★★☆☆ / 파급력 ★★★☆☆ / 격조 ★★★★★ / 리스크↓ ★★★★☆
- **강점**: ① 무엇을 하는 채널인지 가장 명확 ② 롱폼·강의로 확장할 때 격이 맞음 ③ 유료 상품 신뢰도 높음
- **약점**: ① 개성이 약해 비슷한 이름 사이에 묻힘 ② 숏폼 특유의 가벼움과 거리감
- **리스크**: 일반명사 조합이라 상표 식별력 약할 수 있음
- **적합 라인**: 공고 분석 롱폼, 컨설팅·강의 연계

## 4. 그랜트노트 Grant Note (한·영 하이브리드)

- **어원·의미**: Grant(지원금) + Note(노트). 정리 노트 느낌
- **이미지 키워드**: 깔끔 · 정리 · 스타트업 · 모던
- **5축**: 직관성 ★★★☆☆ (Grant 인지도 낮음) / 확산성 ★★★☆☆ / 파급력 ★★★☆☆ / 격조 ★★★★☆ / 리스크↓ ★★★☆☆ (유사 영문 서비스명 가능성)
- **강점**: 영문 도메인·핸들 만들기 쉬움, 세련됨
- **약점**: 한국 지원사업 수요층(예비창업자·소상공인)에게 거리감

## 5. 등대공고 (자연·해양 모티프)

- **어원·의미**: 부산 항구의 등대 = 길잡이. 공고의 바다에서 길을 알려준다
- **이미지 키워드**: 길잡이 · 부산 · 바다 · 방향 · 따뜻함
- **5축**: 직관성 ★★★☆☆ / 확산성 ★★★☆☆ / 파급력 ★★★★☆ / 격조 ★★★★☆ / 리스크↓ ★★★★☆
- **강점**: 이야기가 있는 이름, 로고 모티프 명확(등대 불빛)
- **약점**: '방법' 채널이라는 기능이 이름에서 안 보임

## 6. 공고한장 (산업어 + 포맷)

- **어원·의미**: 공고 하나를 한 장으로 정리. 포맷 자체가 이름
- **이미지 키워드**: 요약 · 한눈에 · 실용 · 빠름
- **5축**: 직관성 ★★★★☆ / 확산성 ★★★★☆ / 파급력 ★★★☆☆ / 격조 ★★★☆☆ / 리스크↓ ★★★★☆
- **강점**: 쇼츠 포맷과 딱 맞음, 시리즈화 쉬움
- **약점**: 개별 공고 요약 채널로 한정되어 '방법' 콘텐츠와 어긋남
