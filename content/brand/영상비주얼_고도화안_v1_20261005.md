## 1. 결론

○ **기본은 A안(코드로 그린 마스코트 '단디' + 아이콘 애니메이션)으로 매일 자동 제작**
- 비용 0원이고, 그림체가 매번 같습니다. 1편 시안을 완성했습니다.
○ **B안(AI 일러스트)은 주 1~2편, 영상 첫 장면(썸네일)에만 쓰는 것을 권장합니다**
- 결제를 연결해야 하고, 그림체가 편마다 흔들릴 위험이 있습니다.
○ **C안(AI 영상 Veo)은 채널 소개·광고용 3~8초 클립에만 씁니다**
- 초당 과금이라 매일 쓰기에는 비쌉니다.

## 3. A안 상세 (적용 준비 완료)

- **캐릭터:** '단디' — 브랜드 도장 로고를 몸통으로 한 마스코트. 볼에 형광 노랑, 도장 손잡이가 머리.
- **포즈 5종:** 손 흔들기(첫 장면), 가리키기·응원(단계 장면), 생각하기(질문형 훅), 도장 찍기(마지막 장면)
- **움직임:** 통통 튀기, 눈 깜빡임, 팔 동작, 도장 찍는 순간 위아래로 쿵
- **배치:** 화면 오른쪽 아래(쇼츠 버튼·제목 영역은 피함). 자막은 위쪽으로 올림
- **다음 보강(1~2일):** 장면별 소품 아이콘 6종(서류, 달력, 돋보기, 동전, 사람, 시계)을 마스코트 옆에 표시

## 4. B안 적용 방법 (결제 연결 시)

1. AI 스튜디오에서 결제를 연결하고, **월 사용 상한**을 먼저 설정합니다(예: 월 1만 원).
2. 마스코트 기준 이미지 1장을 고정하고, 장면마다 "같은 캐릭터가 ○○하는 장면"으로 생성합니다.
3. 그림 안에는 글자를 넣지 않습니다. 글자는 지금처럼 자막 템플릿이 담당합니다.
4. 생성 실패나 이상한 그림은 A안으로 자동 대체합니다.

## 5. C안 적용 방법 (선택)

- 채널 소개 영상 1편, 상품(가이드) 광고 1편에만 사용합니다.
- 생성 전 대본과 비용을 승인 대기열에 올리고, 사람이 승인한 뒤에만 생성합니다.
