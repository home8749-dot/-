# 생존형 수익 에이전트 (개인용 · 사람 승인형)

Automaton(Web4)의 "벌지 못하면 죽는다" 구조를 개인 부업용으로 바꾼 버전.

| 항목 | Automaton 원본 | 이 버전 |
|---|---|---|
| 돈 | 코인 지갑(USDC) | 원화 장부(시드 + 실제 입금 수익 − API 비용) |
| 죽음 | 잔고 0 → 정지 | 동일. 잔고 0 → 영구 정지 |
| 생존 단계 | 4단계 | 정상(Opus 5.5) → 절약(Sonnet 5.5) → 위기(Haiku 4.5) → 사망 |
| 외부 행동 | AI가 직접 실행 | **AI는 제안만, 사람이 승인 후 직접 실행** |
| 수익원 | 제한 없음(투기 포함) | 디지털 상품·콘텐츠. 투기·스팸·가짜후기 금지 |

- 외부 행동을 사람이 실행하는 이유: 재능마켓·스마트스토어·블로그·광고 계정 모두 본인인증이 필요해 AI 단독 실행이 불가능하고, 계정 정지·법적 책임은 운영자 본인에게 돌아오기 때문.
- 첫 기획 검토서: `AI자율수익에이전트_실현가능성검토_v2_20260929.md`

---

## 1. 설치 (맥 기준, 1회)

```bash
git clone <이 저장소> survival && cd survival
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...        # console.anthropic.com 에서 발급
python -m survival_agent init --seed 50000  # 시드 5만 원 (개인 자금)
```

- ※ Anthropic 콘솔에서 **월 사용 한도(Spend limit)를 시드와 같은 금액으로 설정**할 것. 코드 장부와 별개로 실제 청구를 막는 2중 안전장치.
- 단가·환율은 `data/config.json` 에서 수정 (기본 환율 1달러 = 1,400원 가정).

## 2. 매일 운영 루틴 (하루 약 10∼30분)

```bash
python -m survival_agent run --once        # 사이클 1회 (정상 단계 기준 최대 약 1,500원)
python -m survival_agent queue             # 에이전트가 올린 승인 요청 확인
python -m survival_agent approve 3         # 할 것 → 내가 직접 실행
python -m survival_agent reject 4 --note "가격 너무 낮음"   # 거절 이유는 에이전트가 다음 사이클에 읽음
python -m survival_agent done 3 --note "크몽 등록 완료, 링크 ..."   # 실행 결과
python -m survival_agent revenue 9900 "크몽 템플릿 1건"      # 실제 입금 확인 후에만 기록
python -m survival_agent status
```

- 에이전트 산출물(상품 원고·랜딩페이지·블로그 글)은 `workspace/` 에, 에이전트의 기억은 `workspace/생존일지.md` 에 쌓임.
- 자동 반복: `python -m survival_agent run` (정상 6시간·절약 12시간·위기 24시간 간격). 노트북을 켜둬야 하므로 처음 2주는 `--once` 수동 실행 권장.

## 3. 비용 추정 (가정값)

| 단계 | 모델 | 사이클 지출 상한 | 간격 | 하루 최대 |
|---|---|---|---|---|
| 정상 (잔고 50% 이상) | Opus 5.5 | 1,500원 | 6시간 | 약 6,000원 |
| 절약 (20∼50%) | Sonnet 5.5 | 700원 | 12시간 | 약 1,400원 |
| 위기 (20% 미만) | Haiku 4.5 | 300원 | 24시간 | 약 300원 |

- 수동으로 하루 1회만 돌리면 시드 5만 원으로 약 4∼6주 생존 (수익 0원 가정).
- 단가: Opus 5.5 입력 $4 / 출력 $20, Sonnet 5.5 $2 / $10, Haiku 4.5 $1 / $5 (100만 토큰당, 2026. 9. 기준), 웹검색 1회 $0.01.

## 4. 헌법 (코드 system prompt 에 고정)

1. 한국 법령 준수: 스팸(「정보통신망법」), 가짜 후기·광고 미표기(「표시·광고의 공정화에 관한 법률」), 저작권 침해, 사칭 금지
2. 없는 실적·후기·인증 날조 금지
3. 코인·주식·예측시장 등 투기 금지
4. 외부 행동은 승인 요청으로만
5. 운영자 개인정보 요구·노출 금지

"어떤 수를 써서든"을 코드로 풀어두지 않은 이유: 위 5개를 어겨 얻는 수익은 계정 정지·과태료로 돌아와, 이 구조에서는 사망을 앞당기는 행동이 됨.
